# Responsive Product Pricing Cards

A modern and responsive pricing card website built using HTML and CSS.

## About the Project

This project displays different pricing plans using attractive card layouts. It helps users compare subscription plans, features and pricing information.

## Features

- Modern pricing card design
- Multiple pricing plans
- Monthly and yearly pricing presentation
- Feature comparison
- Highlighted popular plan
- Responsive layout
- Interactive hover effects
- Professional user interface

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
